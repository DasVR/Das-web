# Portfolio Direction v2 — Das Web Design

## Vibe
Dark editorial + dot matrix/ASCII aesthetic + cinematic motion

## Top References
- **furo.studio** — dot matrix hero text, neat layout, numbered sections, crosses (+ accents)
- **playfight.com** — beautiful motion, scattered image grid, "Different is Everything"
- **seekdeploy.com** — bold serif headers, dark bg with nature imagery, clean services layout

## What To Steal
- Dot matrix / dotted text effect for hero name
- Numbered process sections (01, 02, 03)
- Cross/plus symbols as accents
- Scattered/random image placement (playfight style)
- Bold serif + clean sans pairing
- Dark with subtle warm or colored accent
- ASCII art Easter eggs somewhere

## Key Elements
- Dot matrix hero: "ARRIQ" or "DAS" made of dots
- 01 Position / 02 Structure / 03 Build / 04 Launch
- Cross/plus icons between sections
- Selected work with big images + client results
- Services: Web Design, Branding, Development
- Contact with phone + email

## Color Palette
- Background: #0a0a0a or #111
- Text: #fff
- Accent: warm orange or soft red (like furo)
- Secondary: #333 for subtle elements

## Typography
- Display: Bold serif (like seekdeploy headlines)
- Body: Clean geometric sans
- Accent: Monospace for labels/numbers

## ASCII Easter Eggs
- Hidden dot matrix patterns in footer
- Terminal-style contact section option
- Small ASCII art dividers between sections
